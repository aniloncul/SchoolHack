# Ders Notları — Almanca (Chemie, Mol / Stoffmenge)

> Kaynak: 28 Ekim 2026 canlı oturumlar (364562 → devam). Tutor: **Alfrenzo**, dil: `de`, seviye: lise.
> Tüm cümleler yakalanan gerçek tutor konuşmalarından alınmıştır — uydurma yok.

---

## 1. Dersin dil profili

Tutor **informal `du`** kullanıyor, tamamen konuşma dili. Cümleler kısa (ortalama 12–18 kelime), çoğu zaman iki cümle: bir **yönlendirme** + bir **kontrol sorusu**. Kalıp şu:

```
[değerlendirme/duygu] + [yeniden ifade] + [yönlendirme] + [kontrol sorusu]
```

Örnek (gerçek):

> „Ah, fast! Die sechs ist die Ordnungszahl, die sagt uns, wie viele Protonen drin sind."
> „Schau mal auf die andere Zahl in dem Kästchen, die meistens weiter unten steht und eine Dezimalzahl ist."

Bu yapıyı taklit etmek, ALMANCA konuşma pratiği için en verimli kısım: öğretmen gibi konuşmak, dil bilgisini zorunlu kılıyor.

## 2. Konu sözlüğü (Fachwortschatz)

| Almanca | Türkçe | Not |
|---|---|---|
| das Mol | mol (madde miktarı birimi) | `ein Mol`, `in Mol` |

| die Masse | kütle | sembol **m**, birim **g** |

| die Avogadro-Konstante | Avogadro sabiti | `N_A` |
| das Periodensystem (PSE) | periyodik tablo | günlük dilde kısaca **PSE** |
| die Ordnungszahl | atom numarası | „wie viele Protonen drin sind" |
| die Atommasse | atom kütlesi | PSE'deki ondalık sayı |
| das Proton | proton | |
| das Atom | atom | |
| die Prüfung | sınav | `die Semesterprüfung` |
| die Übungsaufgabe | alıştırma sorusu | |
| die Reaktionsgleichung | tepkime denklemi | |
| die Konzentration | derişim | |
| das Gasvolumen | gaz hacmi | |
| die Bindung | bağ | `chemische Bindung` |
| die Säure / die Base | asit / baz | |

**Komposita (bileşik isim) mantığı** — Almanca'nın en verimli öğrenme alanı:

```
Stoff + Menge        = Stoffmenge
Teilchen + Zahl      = Teilchenzahl
Ordung(s) + Zahl     = Ordnungszahl
Atom + Masse         = Atommasse
Semester + Prüfung   = Semesterprüfung
Übung(s) + Aufgabe   = Übungsaufgabe
```

> Kural: son unsur cinsiyeti belirler → `die Menge`, `die Zahl`, `die Masse`, `die Prüfung`, `die Aufgabe`. Hepsi **die**.

## 3. Tutor'un kalıp ifadeleri (Redemittel)

### Derse giriş / çerçeveleme
| Almanca | Türkçe |
|---|---|
| „Das Ziel heute: Du kannst … sicher lösen." | Bugünün hedefi: …'yı güvenle çözebilmen. |
| „Und so gehen wir vor." | Şöyle ilerleyeceğiz. |
| „Erst ganz kurz, was ein Mol überhaupt ist." | Önce kısaca mol nedir. |
| „Wenn was unklar ist, frag einfach zwischendurch." | Bir şey net değilse arada soruver. |
| „Passt der Plan so für dich?" | Plan sana uygun mu? |

### Yönlendirme (en sık kullanılan)
| Almanca | Türkçe | Dilbilgisi |
|---|---|---|
| „Schau mal auf das Bild." | Bir de resme bak. | `schauen` + **auf** + Akkusativ |
| „Schau mal hier auf mein Board." | Burada benim tahtama bak. | |
| „Guck mal direkt unter das O." | Doğrudan O'nun altına bak. | `gucken` = konuşma dili |
| „Probier's mal kurz aus." | Bir kere dene. | `probier's` = `probiere es` |
| „Stell dir ein Mol wie eine riesige Packung vor." | Mol'ü kocaman bir paket gibi düşün. | `sich (dat) etwas vorstellen` — ayrılabilir fiil |
| „Merk dir einfach: …" | Şunu aklında tut: … | `sich (dat) merken` |
| „Du schnappst dir einfach dein Periodensystem." | Periyodik tablonu alıver. | `sich (dat) schnappen` |

### Değerlendirme / düzeltme
| Almanca | Türkçe |
|---|---|
| „Ah, fast!" | Ah, neredeyse! |
| „Hmh.. da bist du gerade wieder bei Kohlenstoff gelandet." | Hmm, yine karbona döndün. |
| „Gar kein Problem!" | Hiç sorun değil! |
| „Kein Stress, dafür bin ich ja da!" | Stres yok, zaten bunun için buradayım! |
| „Ganz wichtig für die Formeln: …" | Formüller için çok önemli: … |
| „Diese Formel hier ist der absolute Chef." | Bu formül işin patronu. (argo/ifade) |
| „Die ist der Kern von fast jeder Aufgabe." | Neredeyse her sorunun özü bu. |

> **Dikkat — düzeltme tekniği:** Tutor hatayı asla „falsch" diye kesmiyor. Önce duygusal tampon („Ah, fast!", „Hmh.."), sonra **doğru bilgiyi cümle içinde** veriyor, sonra yeni bir yönlendirme. Bu, Almanca'da geri bildirim verirken kullanılacak en yumuşak kalıp.

### Cesaretlendirme
- „Perfekt, ziehen wir das durch!" — Mükemmel, bunu sonuna kadar götürelim.
- „Also kein Rumtrödeln, wir machen das direkt prüfungsfit." — Oyalanmak yok, doğrudan sınava hazır hale getiriyoruz.
- „ohne zu zittern" — titremeksizin.

## 4. Kendi cümlelerin → düzeltilmiş hali

Bunlar oturumda gerçekten yazdığın mesajlar:

| Yazdığın | Doğrusu | Açıklama |
|---|---|---|
| `mol rechnen und es it morgern` | **Molrechnen, und es ist morgen.** | `it` → `ist` (harf düşmesi), `morgern` → `morgen` (fazladan r). Ayrıca `es ist morgen` = „yarın" (sınav bağlamında doğal). |
| `passt gut` | **Passt gut.** ✅ | Doğru ve doğal. „Uyar / tamam" anlamında. |
| `nein` | **Nein.** ✅ | Tek başına yeterli, ama daha doğal: „Nein, noch nicht." |
| `ich weiss nicht` | **Ich weiß nicht.** | `ss` yerine **ß** (weiß), büyük harf `Ich`. |
| `6` / `12,01` | — | Sayıda ondalık **virgül**: `12,01` ✅ (Almanca'da nokta değil) |

> **Tutor'ın sessiz düzeltmesi:** Sen `mol rechnen und es it morgern` yazdın, tahtaya **„Thema: Rechnen mit dem Mol / Prüfung: morgen"** olarak geçirdi. Yani hatalı girişi görünmez şekilde normalize ediyor — dil öğrenimi açısından bu iyi bir tasarım, ama düzeltmeyi *göstermediği* için sen fark etmiyorsun. Kendi yazdıklarını geri okuyup karşılaştır.

## 5. Sayı ve formül okuma (sınavda sesli okutulur)

| Yazılış | Almanca okunuş |
|---|---|
| 6,022 · 10²³ | *sechs Komma null zwei zwei mal zehn hoch dreiundzwanzig* |
| 12,01 | *zwölf Komma null eins* |
| 15,999 | *fünfzehn Komma neun neun neun* |
| n = m / M | *n gleich m durch M* |
| N = n · N_A | *N gleich n mal N-A* |

**Kritik fark:** Türkçe'de "bölü" = `geteilt durch` / `durch`; "çarpı" = `mal`. Sınavda formülü sözlü açıklarken bunlar şart.

> Tutor cümlesi: „Wenn du m suchst, hältst du es zu und rechnest **n mal M**. Wenn du n suchst, rechnest du **m geteilt durch M**."

## 6. Dilbilgisi gözlemleri (dersten çıkarılan)

**a) Modal partikeller — konuşma dilinin kalbi**
- `mal` → yumuşatma: *Schau **mal***, *Probier's **mal** aus*, *Guck **mal***
- `ja` → ortak bilgi/vurgu: *dafür bin ich **ja** da*
- `doch` → itiraz/kabul: *Zieh das **doch** durch*
- `einfach` → basitlik: *frag **einfach** zwischendurch*, *Du schnappst dir **einfach** dein PSE*

Bu dört kelime olmadan Almanca konuşma "ders kitabı" gibi durur; ekleyince native'e yaklaşır.

**b) Ayrılabilir fiiller (Trennbare Verben)**
| Fiil | Ayrılmış hali |
|---|---|
| vorstellen | *Stell dir … **vor*** |
| ausprobieren | *Probier's mal **aus*** |
| durchziehen | *ziehen wir das **durch*** |
| aufschreiben | *Hab ich hier **auf**geschrieben* |
| mitkommen | *kommt … **dran*** (dran = daran) |

**c) `dran` / `daran` — konuşma dilinde çok sık**
- *Was kommt **dran**?* = Ne çıkacak? (sınav konusu)
- *…, ob noch was anderes **dran** kommt* = başka bir şey de var mı

**d) Edat + hâl (Wechselpräpositionen)**
- `auf` + **Akkusativ** (yön): *Schau auf **das** Bild*, *unter **das** O*
- `in` + **Dativ** (konum): *in **dem** Kästchen*, *im Periodensystem*

## 7. Kendine pratik — 8 kalıp

Aşağıdakileri ders bittikten sonra sesli tekrar et; her biri derste geçen gerçek bir yapı:

1. **Schau mal auf** das Periodensystem. **Was steht da bei** Sauerstoff?
2. **Ein Mol ist** einfach eine Zahl, **so wie** ein Dutzend.
3. **Die kleine Zahl oben ist** der Platz im Periodensystem, **die größere unten ist** das Gewicht.
4. **Wenn** du die Masse suchst, **rechnest du** m geteilt durch M.
5. **Ich weiß nicht**, **wie** man das rechnet. — **Kannst du** das **noch mal** erklären?
6. **Das kann am Anfang verwirren**, besonders **wenn** man morgen die Prüfung hat.
7. **Merk dir einfach:** Die Formel ist der Kern von fast jeder Aufgabe.
8. **Passt der Plan so für dich, oder** kommt noch was anderes dran?

> 5. cümle özellikle önemli: „Ich weiß nicht" demek yerine **„Ich weiß nicht, wie man das rechnet"** demek, cümleyi yan cümleye çeviriyor → `wie` + fiil sonda. Sınavda puan getiren yapı.

## 8. Öğrenme açısından ürünün iyi/kötü yanları

**İyi:**
- Tutor senin seviyene göre **kısa cümle** kuruyor, uzun yan cümlelerden kaçınıyor.
- Her yeni kavramı **tahtaya yazıp** aynı anda **sesli** söylüyor → çift kanal.
- Hatalı girişini tahtada düzeltiyor (girdi normalizasyonu).
- „Merk dir einfach" kalıbı ile özet veriyor — not almaya birebir uygun.

**Zayıf:**
- **Yazılı düzeltme yok.** `it` → `ist` hatasını hiç söylemedi. Dil öğrenimi için bu büyük eksik; hataları görmek istiyorsan kendi mesajlarını transcript'ten karşılaştır.
- Metinler `text` alanında düz string, telaffuz geri bildirimi yok.
- Almanca öğretmeni olarak tasarlanmamış — kimya öğretiyor, dil düzeltmiyor.
